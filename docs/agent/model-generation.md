# Model references and non-chat generation

Use [models](models.md) for the decision rule. Before native generation, read Pi's codemode API documentation; it owns exact calls.

## Model references

models.reference returns canonical <cake-model> JSON text for insertion through ordinary messages; no desktop/caret control is required. Composing chips can be edited; sent chips are read-only. References never switch models or launch work.
The snapshot contains provider/modelId/thinkingLevel/fastMode and optional preset:{id,prompt?}, plus display-only presetName. Pass the settings and optional preset to a requested launch, excluding presetName; preserve edited effort/Fast overrides.
Drafts/queues/recovery/Pi history store the same text, not separate chip state. Copying a chip copies canonical text; invalid tokens remain literal.
A reference alone is not authorization to create an agent.

## Resolve a preference

Inside codemode, call tools.cake with command:models.select-non-chat and input:{type:"image"}. Typed return is {command,result}; use result.model with models.generateImages.
If null, discover models.getAvailableOfType("image"). Explicit requested:{provider,modelId} overrides preference.
Unavailable requested/preferred models require asking before billed substitution. Preferences are advisory, not access restrictions.
For classifiers use type:"classifier", then models.classify(model,{state,questions}). Preferences do not enable automatic routing/background classification. Never select an image model as the chat model.

## Generation and errors

Built-in image models use OpenRouter credentials, not ChatGPT subscription authentication. Eligible Project Sessions enable codemode by default; explicit tool selections/disabled extensions/restricted chats may exclude it. Explain the missing capability; never invent providers/auth. Pi defaultTools:["+codemode"] enables it in eligible sessions.
models.generateImages(model,{input}) accepts text and supported base64 reference-image blocks. Read source bytes through file tools; do not shuttle base64 through prose.
Check stopReason/errorMessage and output truncation. Report errors/cancellation honestly. Show images via image(block), text via text(block.text); do not print/store image bytes in codemode's JSON store.

## Requested original-byte saving

Generation alone does not save workspace files. When requested, save original generated bytes in the same script before returning the preview.
Stage base64 in a temporary file with tools.write; decode/write using tools.bash and Node, then remove the temporary file. Do not put large base64 in shell arguments (OS limits).
Quote paths, honor destination/overwrite intent, verify the file, then show it inline by Markdown image path.
Transcript previews may be resized and unsaved originals unrecoverable. Never silently regenerate a billed image merely to save it.
