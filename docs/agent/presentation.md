# Presentation

## Text, images and files

app.user-selection reads highlighted Cake text.
Use Markdown/GFM, Mermaid and $ math; no raw HTML/JSX. Use $...$ and $$...$$, not backslash-parenthesis/bracket math delimiters.
Images: ![description](/absolute/path), inline; ~/ also works. Do not copy images into the workspace merely to show them; native generated image blocks also display inline.
Other files: relative Markdown links; ranges use #L5-L10,L20-L25, diffs ?view=changes&side=before. Use absolute paths only outside the Working Directory; those open read-only.
Requested file deliverables remain files, not decorative HTML. Ordinary plans/reports stay in chat.

## Sources and existing artifacts

Sessions: [title](cake://session/id). Reports: exact original ref labeled "Full agent response"; never internal reminder/private Pi ID.
Subagent links use the public parent/handle and exact original message when available. If only a public conversation ref exists, use it without inventing a message.
messages.present explicitly shows a source without rereading; source expansion is not model inspection. Incoming report cards need no recap or relay.
artifacts.present shows existing content; do not regenerate it. Presentation is not inspection.
Permanent chats can present accessible cross-session references, linking as needed; Project Sessions need an effective link first. Repeated presentation adds an inline surface, not a source revision. Widgets use live lineage state even with pinned source.

## New visual output

html.present {id,title,html,height?}: static sandbox, no scripts/network/host styles. Supply colors/fonts. Publication is not visual verification; disclose missing pixel checks.
Use widgets.present for interaction; loaded skill templates use their complete widgets.instantiate call directly.
[Interactions](interactions.md) covers surface selection, sizes and static verification; [approved designs](artifact-designs.md) covers exact preview/selected-state evidence. Keep conversation primary; no terminal-only UI directions.
